# nvdb-vegref-api

Klasser for å hente historiske vegsystemer og vegreferanser fra NVDB.

Kopier filene i src inn i ditt javascript-prosjekt og bruk
funksjonen i vegrefController til å  hente historiske 
vegreferanser fra NVDB.


___


To install dependencies:

```bash
bun install
```

To run tests:

```bash
cd src/tests && bun test
```

_____
This project was created using `bun init` in bun v1.3.1. [Bun](https://bun.com) is a fast all-in-one JavaScript runtime.
